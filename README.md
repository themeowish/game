# 飞行棋游戏项目

这是一个基于 React 开发的飞行棋游戏项目，使用 [Create React App](https://github.com/facebook/create-react-app) 创建。

## 🚀 快速开始

### 前置要求

- Node.js (版本 14 或更高)
- npm 或 yarn

### 安装步骤

1. **进入项目目录**
   ```bash
   cd flying-chess
   ```

2. **安装依赖**
   ```bash
   npm install
   ```
   或者使用 yarn:
   ```bash
   yarn install
   ```

3. **启动开发服务器**
   ```bash
   npm start
   ```
   或者使用 yarn:
   ```bash
   yarn start
   ```

4. **打开浏览器**
   
   项目会自动在浏览器中打开 [http://localhost:3000](http://localhost:3000)
   
   如果没有自动打开，请手动访问该地址。

### 开发模式特性

- ✅ 页面会在你修改代码后自动重新加载
- ✅ 控制台会显示任何 lint 错误
- ✅ 支持热模块替换（HMR）

## 📜 可用命令

### `npm start`

在开发模式下运行应用。\
打开 [http://localhost:3000](http://localhost:3000) 在浏览器中查看。

页面会在你修改代码后自动重新加载。\
你也会在控制台看到任何 lint 错误。

### `npm test`

启动测试运行器（交互式监视模式）。\
查看 [运行测试](https://facebook.github.io/create-react-app/docs/running-tests) 部分了解更多信息。

### `npm run build`

构建用于生产环境的应用程序到 `build` 文件夹。\
它会以生产模式正确打包 React 并优化构建以获得最佳性能。

构建会被压缩，文件名包含哈希值。\
你的应用已准备好部署！

查看 [部署](https://facebook.github.io/create-react-app/docs/deployment) 部分了解更多信息。

### `npm run eject`

**注意：这是一个单向操作。一旦你执行了 `eject`，就无法回退！**

如果你对构建工具和配置选择不满意，你可以随时执行 `eject`。此命令将从项目中删除单个构建依赖项。

相反，它会将所有配置文件以及传递依赖项（webpack、Babel、ESLint 等）直接复制到你的项目中，以便你完全控制它们。除了 `eject` 之外的所有命令仍然可以工作，但它们将指向复制的脚本，以便你可以调整它们。此时，你需要自己负责。

你不必使用 `eject`。精选的功能集适用于小型和中型部署，你不应该觉得有义务使用此功能。但是，我们理解如果你在准备好时无法自定义它，这个工具就不会有用。

## 🎮 游戏说明

本项目包含两个游戏：
- **飞行棋（激情脱衣版）**：4人游戏（2男2女）
- **三人行**：3人游戏（1女2男）

使用 React Router 进行路由管理，支持多页面导航。
